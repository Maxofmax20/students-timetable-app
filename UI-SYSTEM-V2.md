# UI-SYSTEM-V2.md

## Product feel
V2 should feel like a premium student SaaS: calm, confident, readable, and fast.

## Principles
- Mobile-first before desktop enhancement
- Timetable is the visual anchor
- Dashboard is a daily command center, not a statistics dump
- Strong information hierarchy > decorative noise
- Empty/loading/error states must feel intentional

## Design system direction
- Keep current token-driven system, but evolve toward semantic tokens that support **light and dark mode**.
- Use larger rounded cards, compact chips, strong page intros, and clean list/timeline modules.
- Reserve gold accent as a premium highlight, not as every-surface paint.

## Core reusable patterns
- KPI cards with context, not vanity numbers only
- Quick-add toolbar
- Timeline/list cards for exams and assignments
- Drawer/dialog create-edit flows
- Mobile segmented controls for timetable/day-week switching

## Accessibility and responsiveness
- Touch-friendly spacing on phone
- No dense desktop-only control clusters
- Focus states preserved
- Printed/exported timetable remains readable
